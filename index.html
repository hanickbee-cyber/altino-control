2. 파이썬 코드 입력 (Shift + Enter로 실행)

사용 가능 함수: go(좌, 우), steering(각도), stop()

import js def go(left, right): js.go(left, right) def steering(st): js.steering(st) def stop(): js.stop() # 로봇을 1초 동안 앞으로 이동시킨 후 정지하는 예제 import asyncio async def main(): go(300, 300) await asyncio.sleep(1) # PyScript에서는 딜레이로 asyncio.sleep 사용 stop() import pyscript pyscript.run_until_complete(main())
